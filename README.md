Software engineer in Stockholm. These are the tools I work with every
day, most of them for running coding agents in the terminal.

- [owl](https://github.com/stefanahman/owl): TUI that opens any PR, issue or project as a git worktree with Claude Code
- [spaces](https://github.com/stefanahman/spaces): hotkeys for tmux, herdr and cmux workspaces, pinned to desktop spaces
- [claude-status](https://github.com/stefanahman/claude-status): whether Claude Code is working, blocked or done, in your tmux status bar
- [mcp-defer](https://github.com/stefanahman/mcp-defer): start MCP servers on their first tool call, not at session start
- [mux](https://github.com/stefanahman/mux): one Go interface over tmux, herdr and cmux, for coding agents
- [mindoro](https://github.com/stefanahman/mindoro): a terminal pomodoro whose breaks take over every window
- [eden](https://github.com/stefanahman/eden): dotfiles across machines, a public engine with your private configs on top

The binaries install with Homebrew from [stefanahman/tap](https://github.com/stefanahman/homebrew-tap).

I write at [stefanahman.com](https://stefanahman.com).
